# 燕元 × 燕火 人设演变报告

> **分析范围**：2014 – 2025.8（排除 2025.9.1 及之后语料）
> **语料来源**：`output1/` 下 .md 文件，覆盖约 250 篇推送
> **分析方法**：按三个时期分层抽样（远古期/中期/近期），追踪角色声音、互动模式、梗生态的演变轨迹

---

## 一、时期划分

| 时期 | 年份 | 阶段特征 |
|------|------|---------|
| **远古期** | 2014–2018 | 语C萌芽，角色作为"coser CN"或"看板娘实体"出现，对话尚简单 |
| **中期** | 2019–2022 | 吐槽役/装傻役框架成型，梗密度爆发，管人/VTuber 文化大量涌入 |
| **近期** | 2023–2025.8 | 角色完全成熟，元叙事崛起，自我解构成为常态 |

---

## 二、燕元：从"温柔姐姐"到"腹黑吐槽役"

### 2.1 语气演变

```
远古期 → "赞美大手子们的积极投稿~（流下了不会画画的泪水）"  ← 谦逊温和
中期   → "她病了，是期末击败了她。"                        ← 冷面笑匠
近期   → "……妹妹你够了。"                                ← 一针见血
```

关键转折点在 **2018–2020 年**：燕元从单纯的"信息补充者"升级为"节奏控制者"。她开始用简洁的吐槽截断燕火的暴走，而不是温和地接话。

### 2.2 「……」使用频率

| 时期 | 出现频率 | 功能 |
|------|---------|------|
| 远古期 | **几乎为零** | — |
| 中期 | 偶尔（每 2-3 篇 1 次） | 表达无奈 |
| 近期 | **高频**（每篇 2-3 次） | 角色标识，多功能（嫌弃/假装没听到/制造节奏停顿） |

「……」的崛起是燕元人设变化的最显著指标。它从一个普通的省略号变成了燕元的"注册商标"——读者看到「……」就知道燕元在翻白眼。

### 2.3 句式长度变化

- **远古期**：10-20 字/条，1-2 句
- **中期**：15-30 字/条，偶尔长段介绍
- **近期**：5-40 字/条，两极分化——吐槽用短句（5-10 字），介绍信息用长段

---

## 三、燕火：从"活泼妹妹"到"网络梗达人 + 破壁人"

### 3.1 语气演变

```
远古期 → "姐姐姐姐！新社衫好好看！"                      ← 单纯活泼
中期   → "■■真是太可爱了！！！！"                        ← 花痴安利狂魔
近期   → "检测到宿主重生回百团大战，社团系统激活——"        ← 网络梗集合体 + 第四面墙破坏者
```

### 3.2 感叹号密度

| 时期 | 密度 |
|------|------|
| 远古期 | 1-2 个/段 |
| 中期 | 3-5 个/段（峰值，如"■■太可爱了！！！！"） |
| 近期 | 2-4 个/段（回落到可控范围，但配合颜文字/emoji 制造同等强度） |

### 3.3 颜文字进化史

```
远古期 → 无
中期   → (✧◡✧)  0.0  （开始出现）
近期   → T^T  TvT  👁👁👁👁👁👁  _(´ཀ`」 ∠)_  （已成为燕火的语言基因）
```

### 3.4 「姐姐」称呼频率

| 时期 | 每篇出现率 |
|------|-----------|
| 远古期 | 80%+ 的对话段 |
| 中期 | 60% |
| 近期 | 40-50%，部分段完全不叫 |

燕火对燕元的称呼从"必须喊姐姐"变成了"需要时才喊"——她越来越独立于"妹妹"这个身份框架之外。

## 四、互动模式的演化

### 4.1 谁先开口？

| 时期 | 燕火先手 | 燕元先手 |
|------|---------|---------|
| 远古期 | 80% | 20% |
| 中期 | 70% | 30% |
| 近期 | 60% | 40% |

燕元逐渐获得"主动开场"的权利——尤其是在 repo 和正式公告类推送中。

### 4.2 对话模板的代际更迭

```
远古期：燕火号召 → 燕元补充 → 一起介绍活动
中期  ：燕火发疯 → 燕元吐槽 → 一起介绍活动
近期  ：燕火燕元用无意义对话开场 → 互相同人设定 → 自己吐槽推送写得越来越长 → 才进入正题
```

近期的模板本质上是**对模板本身的解构**。2024 年后的推送中，"这段介绍都包浆了"和"那个推送我们咕咕了"已经是固定梗。

### 4.3 新互动类型：设定维护

近期出现了一种全新的互动——角色之间互相调侃对方的"设定"：

> 燕元："妹妹，我听说前阵子你好像有了个光棒痴的设定。"
> 燕火："诶，有、有吗？！"

角色设定不再是被写手单向赋予的，而是角色自己可以调侃、维护、甚至否认的对象。这是语C成熟到能自我指涉的标志。

## 五、梗生态的演变

### 5.1 梗源代际更替

| 时期 | 主力梗源 | 代表作品 |
|------|---------|---------|
| 远古期 | 当季热门番剧 | Fate/Grand Order, Re:Zero, 阴阳师, 你的名字。 |
| 中期 | 游戏+管人文化 | 原神, VOCALOID, VTuber, 明日方舟 |
| 近期 | 迷因+网文+meta | MyGO!!!!!, 系统流/重生文, 管人通用语, 元火内部梗 |

### 5.2 梗替换速度

```
远古期：约 12 个月（跟着番剧季度走）
中期  ：约 6-9 个月（网络梗加速迭代）
近期  ：3-6 个月（迷因爆发式传播，一个梗几周就过气）
```

### 5.3 关键转折：MyGO 入侵（2023）

MyGO!!!!! 在 2023 年夏天播完后迅速成为元火内部的第一大梗源，几乎取代了 Fate 系列的"经典梗"地位。代表句式：
- "为什么要xxx！"（为什么要演奏春日影.jpg 格式）
- "组一辈子元火好吗……"
- "你这个人，满脑子都只想着大家呢"

MyGO 的特殊之处在于它的台词天然适合吐槽役/装傻役的语C框架，因此融入速度远超之前的任何作品。

## 六、最重要的五个变化趋势

### 趋势 1：吐槽浓度持续上升
燕元的吐槽从"温和补充"变成"冷面毒舌"，燕火的装傻从"单纯活泼"变成"梗驱动疯癫"。两人之间的张力从 3:7 变成了接近 5:5——燕元越来越敢说。

### 趋势 2：第四面墙变薄
远古期语C是完全的"角色扮演"模式。近期角色已经意识到自己是被语C的角色，会直接调侃"宣传部 staff"、吐槽"这个对话已经重复了好几个推送了"。元叙事成为常态。

### 趋势 3：称呼的松弛化
"妹妹""姐姐"从远古期的"每段都要叫"变成近期的"想起来才叫"。角色关系从"依赖型姐妹"进化为"损友型搭档"。

### 趋势 4：梗从"引用"变成"语言"
早期是在对话中引用 ACG 作品的台词。近期燕火的语言本身就是梗的混合物——她不再「引用」梗，她「是」梗。

### 趋势 5：气泡长度的两极分化
燕元吐槽越来越短（5-10 字），燕火暴走越来越长（可达 40 字高速神言）。对比远古期两人都是 10-20 字的均匀气泡，近期的对话节奏更加戏剧化。

## 七、与当前 SKILL.md 角色圣经的对照

当前 `character-bible.md`（2025-2026 版）对燕元燕火的定义总体上准确捕捉了近期（2023-2025.8）形成的角色定型。但以下细微差异值得注意：

| 维度 | character-bible.md 描述 | 远古-中期语料实际 | 趋势 |
|------|------------------------|------------------|------|
| 燕元「……」 | 定位为"最频繁" | 远古期几乎为零 | ✅ 近期吻合 |
| 「ohno妹妹何意味」 | Top 10 口头禅 | 仅近期零星出现 | 可能是 2025.9 后的新梗 |
| 「鸡煲」「蛇咬好牌多抓」 | 列为燕元口头禅 | 中期 Killing Spire 梗确有使用 | ✅ 有历史依据 |
| 燕火「EL PSY CONGROO!」 | Top 5 口头禅 | 中期高频，近期减少 | 可能是历史梗的保留 |
| 颜文字种类 | 列举了约 6 个 | 近期实际使用远超此数 | 颜文字库需要扩充 |
| 「贴贴」「尊い」 | 归入燕火常用 | 主要出现在 2023.9 后 | ✅ 近期吻合 |
| 姐妹关系"模式A-F" | 6 种固定模式 | 近期模式 A 和 B 占比 70%+ | 模式分布不均衡 |

> **核心结论**：当前 character-bible 的人设基准在近期语料上是准确的。差异主要集中在（1）部分口头禅可能是 2025.9 之后才引入的（不在本分析范围），（2）颜文字/梗的实际使用比圣经更丰富。

## 八、对 skill 写作的建议

1. **燕元的「……」不可滥用**：虽然是角色标志，但远古期燕元也曾是"不沉默的姐姐"。如果每段都用「……」开场，角色会失去层次。
2. **燕火的高速神言需要刹车**：近期的极长气泡（40 字+）在手机上阅读体验不好。建议控制在 25 字以内。
3. **"妹妹""姐姐"不要完全消失**：虽然近期松弛化了，但这是姐妹关系的锚点。每篇至少 2-3 处保留称呼。
4. **梗密度有天花板**：近期推送中有些开场白连续 3-4 轮全是梗，对非核心读者不友好。保留 1-2 处信息性对话。
5. **元叙事适可而止**："这个对话重复了好几个推送了"这种自嘲很好，但如果每篇都来一次就失去了新鲜感。
