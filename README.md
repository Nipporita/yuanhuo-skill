# 元火娘.skill

北京大学元火动漫社 微信公众号语C文案写作 Skill —— Claude Code 插件。

燕元（姐姐·蓝气泡·吐槽役）和燕火（妹妹·红气泡·装傻役）是元火动漫社的拟人化吉祥物，以聊天气泡的形式出现在几乎所有公众号推文中。本 Skill 辅助宣传部撰写这些对话文案。

> 📱 **推荐阅读**：[`README.html`](README.html) —— 用燕元燕火的聊天气泡写成的 README，元叙事拉满。

## 快速开始

在 Claude Code 中说：

> 「帮我写一篇本周活动的语C文案：周五例会 21:00 二教525，周六茶绘 13:00-18:00 二教424，周六放映会 18:30 二教525 播《xxx》」

AI 会自动加载 Skill，生成燕元燕火的聊天气泡文案并导出 HTML。

## 支持的六种推文格式

从元火历史上 1470+ 篇推文中提炼：

| 格式 | 用途 | 对话占比 | 示例 |
|------|------|---------|------|
| A 本周活动 | 多活动周常（最高频） | 5-15% | `examples/example-本周活动-例会茶绘放映会.html` |
| B 特殊放映会 | 单一活动深度介绍 | 20-30% | `examples/example-特殊放映会-虚构作品.html` |
| C repo | 活动图文回顾 | 40-60% | `examples/example-repo-春季迎新晚会.html` |
| D 招募 | 节目/人员招募 | 5-10% | `examples/example-招募-春季晚会.html` |
| E 社萌 | 投票/评比 | 15-20% | `examples/example-社萌-2026最萌大会.html` |
| F 节目预热 | 晚会前节目单预告 | 15-20% | `examples/example-晚会节目预热-春季晚会.html` |

所有示例含对应 CSS 样式及 PNG 截图预览。

## 核心特性

- **角色声音铁律**：燕元 = 吐槽役（「……」、叫「妹妹」、蓝气泡），燕火 = 装傻役（感叹号、颜文字、叫「姐姐」、红气泡）
- **三时期风格系统**：远古期（2014-18）→ 中期（2019-22）→ 现代期（2023-），由全量语料归纳，用户可指定，默认现代期
- **10 种写手人格**：MyGO中毒者、EVA信者、VOCALOID厨、东方民、型月重工、特摄厨、机战狂、旮旯给木玩家、一般通过萌豚、百合豚——每次写作前随机抽选，让 fandom 偏好在对话中自然流露
- **联网感知时兴梗**：每次写作前用 B站/贴吧/小红书搜索矩阵感知当下流行梗，语C 必须活在当下
- **校历感知**：感知北大校历状态，期末季不写「快来玩」写「喘口气」
- **YAU 清华梗素材库**：丘成桐语录是元火传统艺能
- **HTML 生成铁律**：AI 生成声明 + 作者署名「元火娘.skill」
- **对话简短**：每条 10-25 字，超过 35 字太长了
