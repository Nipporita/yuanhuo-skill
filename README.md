# 元火.skill

北京大学元火动漫社 微信公众号语C文案写作 Skill。

燕元（姐姐·蓝气泡·吐槽役）和燕火（妹妹·红气泡·装傻役）是元火动漫社的拟人化吉祥物，以聊天气泡的形式出现在几乎所有公众号推文中。本 Skill 辅助宣传部撰写这些对话文案。

## 快速开始

在 Claude Code 中说：

> 「帮我写一篇本周活动的语C文案：周五例会 21:00 二教525，周六茶绘 13:00-18:00 二教424，周六放映会 18:30 二教525 播《xxx》」

AI 会自动加载 Skill，生成燕元燕火的聊天气泡文案并导出 HTML + PNG 预览。

## 支持格式

| 格式 | 用途 | 示例 |
|------|------|------|
| A 本周活动 | 多活动周常 | `examples/example-本周活动-例会茶绘放映会.html` |
| B 特殊放映会 | 单一活动深度介绍 | `output/`（本地参考） |
| C repo | 活动图文回顾 | `examples/example-repo-春季迎新晚会.html` |
| D 招募 | 节目/人员招募 | `examples/example-招募-春季晚会.html` |
| E 社萌 | 投票/评比 | `examples/example-社萌-2026最萌大会.html` |
| F 晚会节目预热 | 节目单预告 | `examples/example-晚会节目预热-春季晚会.html` |

所有示例含对应 PNG 截图。`output/` 目录（gitignored）存放带真实信息的本地参考文件。

## 核心规则

- **角色声音优先于一切**：燕元 = 吐槽役（「……」、叫「妹妹」、蓝气泡），燕火 = 装傻役（感叹号、颜文字、叫「姐姐」、红气泡）
- **标题格式**：`【活动类型】具体内容`，不加 emoji 前缀
- **对话简短**：每条 10-25 字，超过 35 字太长了
- **写手人格**：每次写作前从 9 种人格中随机抽取，让 fandom 偏好自然流露
- **时兴梗**：联想 B 站梗百科/梗指南，仅用播放量 10 万+ 的出圈梗
