# 推文类型与结构模板

> 元火公众号推文分为 4 种主要类型。不同类型中语C对话的占比和功能不同。

---

## 类型一：【本周活动】—— 多活动周历

### 特征
- 罗列本周 2-4 个活动
- 每个活动有独立的时间、地点、简介
- 对话占比：15-25%

### 结构模板
```
[封面图]

[燕火开场白] 1-2轮对话引入周末活动季
[燕元补充]   自然过渡到活动介绍

[蓝色分隔线]

一、【活动1名称】
[时间图标] 时间
[地点图标] 地点
[活动简介/图片]

[可选：1轮简短评论]

二、【活动2名称】
[时间图标] 时间
[地点图标] 地点
[活动简介/图片]

[可选：1轮简短评论]

三、【活动3名称】
...

[蓝色分隔线]

[燕火] 意犹未尽/期待大家来玩
[燕元] 温暖总结 + 「喜欢您来」
[姐妹合照]
```

### 对话风格
- 轻量、快速，不抢活动信息的重点
- 燕火一句话表达兴奋，燕元一句话引导看具体信息
- 活动之间的评论简短（各1轮即可）

---

## 类型二：【repo】—— 活动回顾报道

### 特征
- 活动已结束，以照片+节目介绍+CAST表为主
- 对话占比：30-40%
- 对话量最大、最自由的类型

### 结构模板
```
[封面图/活动现场图]

[燕火开场] 感叹活动太精彩了/时间线混乱梗
[燕元接话] 补充背景或吐槽推送发晚了

[蓝色分隔线]

**节目板块标题**

[节目1名称/表演者]
[节目1照片]
[燕火评论] 感叹/玩梗/感动
[燕元评论] 补充细节/温和吐槽/磕CP

[节目2名称/表演者]
[节目2照片]
[燕火评论]
[燕元评论]

...（每个节目都穿插评论）

[蓝色分隔线]

**彩蛋/花絮板块**
[花絮照片]
[对话评论]

[蓝色分隔线]

**CAST / STAFF 名单**

[燕元感谢] 感谢所有参与者的付出
[燕火收尾] 期待下次活动
[姐妹合照]
```

### 对话风格
- 自由度高，可以充分玩梗
- 燕火：情绪化评论（感动/兴奋/玩梗/吐槽）
- 燕元：补充节目细节、磕CP、介绍表演者背景
- 可以有连续多轮纯对话（不穿插活动信息）

---

## 类型三：【活动预告/预热】—— 单一活动宣传

### 特征
- 预告一个即将举办的活动
- 重点：传递时间、地点、内容、亮点
- 对话占比：20-30%
- 开头和结尾对话强烈，中间以信息为主

### 结构模板
```
[封面图]

[燕火开场] 兴奋引入活动主题
[燕元开场] 补充关键信息

[蓝色分隔线]

**活动名称/标题**

[时间图标] 活动时间
[地点图标] 活动地点

[活动详细介绍]
[活动亮点/福利]
[活动照片]

[可选：中间穿插 1-2 轮对话]

[报名方式/注意事项]

[蓝色分隔线]

[燕火] 号召大家来参加
[燕元] 温暖邀请 + 「不见不散」
[姐妹合照]
```

### 对话风格
- 开场要有冲击力（燕火的兴奋 + 燕元的点睛）
- 中间对话克制，让信息说话
- 结尾热情洋溢的邀请
- 可以使用「时间线」梗来串联

---

## 类型四：【招募】—— 人员招募

### 特征
- 招募 staff / 演员 / coser 等
- 信息密度最高
- 对话占比：10-15%
- 对话极度轻量化

### 结构模板
```
[封面图]

[燕火发言] 假装不知道要招募 / 或直接cue招募主题
[燕元发言] 揭穿/正式引出招募信息

[蓝色分隔线]

**招募岗位列表**

[岗位1]：人数、职责、要求
[岗位2]：人数、职责、要求
...

[报名方式]
[截止日期]
[联系方式/二维码]

[蓝色分隔线]

[燕火] 轻松号召
[燕元] 正式邀请 + 「总之请报名！」
[姐妹合照]
```

### 对话风格
- 最克制、最短
- 可以玩「燕火自己也想报名」之类的梗
- 燕元负责正式传达招募信息
- 可以用 meta 梗调侃招募推送本身

---

## 各类型对话占比速查

| 类型 | 对话占比 | 燕火功能 | 燕元功能 |
|------|---------|---------|---------|
| 本周活动 | 15-25% | 轻量兴奋、串场 | 轻量补充、过渡 |
| repo | 30-40% | 情绪评论、玩梗 | 补充细节、磕CP |
| 预告/预热 | 20-30% | 强力开场、号召 | 信息补充、邀请 |
| 招募 | 10-15% | 轻松气氛制造 | 正式传达信息 |
