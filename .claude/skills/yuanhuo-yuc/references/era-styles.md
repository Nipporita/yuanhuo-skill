# 元火娘语C时期风格档案

> 基于 output1/ 中 1471 篇推送（含 775 篇语C对话）全量阅读归纳。
> 三个时期各有鲜明的语C风格，写作时可按需模仿特定年代。

---

## 时期速查表

| 时期 | 年份 | 关键词 | 一句话总结 |
|------|------|--------|-----------|
| **远古期** | 2014–2018 | 朴素姐妹 | 燕元温和、燕火单纯，语C尚在萌芽 |
| **中期** | 2019–2022 | 框架成型 | 吐槽役/装傻役定型，管人文化涌入 |
| **现代期** | 2023– | 元叙事·完全体 | 第四面墙破裂，MyGO 统治，角色自觉——仍在演进中 |

## 一、远古期（2014–2018）——「朴素姐妹」

### 燕元
- **语气**：温和、谦逊、直白。「赞美大手子们的积极投稿~（流下了不会画画的泪水）」
- **「……」**：几乎不用。沉默尚未成为她的武器。
- **句式**：10-20 字/条，陈述为主，偶尔反问
- **称呼**：「妹妹」每段必叫
- **功能**：信息补充者 + 温暖收尾。不会主动吐槽燕火，更多是接过话头往下说
- **禁止使用**：腹黑吐槽、冷面笑匠式回应、网络烂梗

### 燕火
- **语气**：单纯活泼。「姐姐姐姐」几乎每段开头
- **感叹号**：1-2 个/段
- **颜文字**：**无**
- **称呼**：「姐姐」每段必叫
- **句式**：短句为主，不玩梗，兴奋直接表达
- **功能**：话题引发者。用最朴素的方式引出活动信息
- **禁止使用**：元叙事、破第四面墙、高速神言、meta 梗、颜文字

### 互动模式
```
燕火：姐姐姐姐！[简单兴奋] → 燕元：[温和回应+补充信息] → 一起介绍活动
```
- 燕火先手 80%
- 轮次比 1:1
- 无括号动作、无物理喜剧

### 梗生态
- **主力**：Fate 系列、Re:Zero、阴阳师、你的名字。
- **风格**：引用当季热门番作为剧情框架包装，不玩梗中梗
- **密度**：低。推送以信息为主，梗只是点缀

### 代表对话
```
燕火：姐姐姐姐，新的社衫设计好好看！
燕元：赞美大手子们的积极投稿~让我们来看看有哪些优秀的设计吧。
燕火：好期待！燕火想穿新衣服！
燕元：元火子们也来投票选出最喜欢的社衫吧~
```

## 二、中期（2019–2022）——「框架成型」

### 燕元
- **语气**：吐槽役成型。从温和姐姐向冷面笑匠过渡。标志性发明——**「翻译：」格式**：
  > 燕火：吼吼，在经历过殊死搏斗与顶级智斗，最终过五关斩六将后——
  > 燕元：翻译：燕火在补完作业、熬过考试、期中寄勉强活过去后，周末要去周常好好玩玩。
- **「……」**：开始出现，偶尔使用（每 2-3 篇 1 次）
- **句式**：15-30 字/条，吐槽用短句，介绍信息时可变长
- **称呼**：「妹妹」频率约 60%，新增威胁语气：「看来这只燕火已经傻了，该准备找找新的元火娘来当妹妹了」
- **新动作**：括号物理喜剧——（手刀）、（给燕火关机）、（捂住燕火嘴）
- **功能**：吐槽 + 信息 + 结构性锚点
- **禁用**：完全的腹黑模式、元叙事自嘲

### 燕火
- **语气**：活泼 + 安利狂魔。「■■真是太可爱了！！！！」（五个感叹号）
- **感叹号**：3-5 个/段——峰值期
- **颜文字**：开始出现 (✧◡✧)、0.0、qwqwq
- **称呼**：「姐姐」频率约 60%
- **网络用语**：开始使用网络流行语——「端上来力——」「传销三连」「画饼ing」
- **新技能**：Blessing Avalanche——高速念完一段祝福：「燕火祝您身体健康学业有成天天开心…（省略一万字）」
- **功能**：话题引发 + 情绪引擎 + 花痴担当
- **禁用**：破第四面墙（除非是 SCP/ARG 实验格式）

### 互动模式
```
燕火发疯 → 燕元降温（吐槽/手刀/翻译） → 燕火再起 → 燕元补充信息 → 合作收尾
```
- 燕火先手 70%
- 出现**实验格式**：SCP 基金会风、西方记者 parody、叙事锚点 ARG

### 梗生态
- **新主力**：原神（2020 后爆发）、VTuber/管人文化、明日方舟、VOCALOID
- **实验性**：SCP Foundation、ARG 叙事、5ch 排版 parody
- **密度**：中高。每篇 2-3 个梗，但非强制
- **社内梗涌现**：「元火子」「黑幕」「内外妇儿」开始形成

### 代表对话
```
燕火：吼吼，在经历过殊死搏斗与顶级智斗，最终过五关斩六将后，英勇的燕火决定去周常休整一番！
燕元：翻译：燕火在补完作业、熬过考试、期中寄勉强活过去后，周末要去周常好好玩玩。
燕火：姐姐！！不要拆穿我嘛——总之元火子们这周末来周常见！！
燕元：好哦好哦。时间地点如下↓
```

## 三、现代期（2023–）——「元叙事·完全体」

> 这是目前最长、仍在演进中的时期。2023 年第四面墙破裂 + MyGO 入侵后，
> 角色声音趋于稳定——吐槽浓度、梗密度、元叙事的核心范式不再发生结构性变化。
> 2025 年底以来的新实验（燕火 solo 推送、AI 模仿秀、写手介入对话、
> 单角色独白格式）属于**范式内的创新**，尚未构成新时期的质变。

### 燕元
- **语气**：腹黑吐槽完全体。「……」成为注册商标。短句一针见血：
  > 燕火高速神言结束后 → 燕元：「……说完了？」「……好中二。」
- **「……」**：高频，每篇 2-3 次。多功能——嫌弃/假装没听到/节奏停顿。2025 年后也用于情感性停顿（温情时刻的前奏）
- **句式**：5-40 字/条，两极分化。吐槽极短（5-10 字），信息介绍可长
- **称呼**：「妹妹」频率约 40-50%。不再每段必叫，更像损友选择
- **新技能**：「设定维护」——调侃燕火的人设：「妹妹，我听说前阵子你好像有了个光棒痴的设定」
- **官号守门人**：偶尔以「官号 guard」身份喝止燕火的出格行为——「这是官号哦燕火，是不是登错账号了」
- **功能**：控制节奏 + 第四面墙同谋 + 偶尔流露温情（围围巾场景等）
- **特征句式**：「……所以」「……妹妹」「（盯—）」「啊啦啊啦」

### 燕火
- **语气**：网络梗达人 + 破壁人。知道自己是语C角色。会抱怨 staff 写的台词：
  > 「不对不对~宣传部staff其实是给我们打工的哦，桀桀桀这就是元火娘的大手……喂等等不要关我的麦！」
- **感叹号**：2-4 个/段，配合颜文字/emoji 制造强度
- **颜文字/emoji**：爆发式增长——T^T、TvT、👁👁👁👁👁👁、_(´ཀ`」 ∠)_。2025 年新增音效词（あははは）
- **称呼**：「姐姐」频率约 40-50%，吃醋/撒娇时高频
- **高速神言**：可长达 40 字，一口气把安利和祝福念完
- **meta 自嘲**：「这段介绍都包浆了」「那个推送我们咕咕了」
- **自介长标签**（2025+ 创新）：「姐姐的好妹妹，元火的可爱吉祥物，社萌表演赛优胜者，人形地铺稀客，大家最爱的白毛蓝瞳，元气（为什么不是火气）美少女·燕火参上！」
- **功能**：气氛制造 + 梗载体 + 第四面墙破坏者
- **特征句式**：「检测到宿主重生回百团大战——」「你是谁？请支持元火动漫社！你说得对但是……（高速神言）」

### 近期创新（2025 年底– ，范式内实验）

以下新格式在现代期后期零星出现，尚未稳定为常规范式，但可用于追求新鲜感的推送：

- **燕火 solo 推送**：燕火「黑入」公众号发独白（如 2026 春节推送），无燕元参与
- **写手介入对话**：宣传部 staff 直接以角色身份进入对话吐槽：「喂喂，你们俩能不能自己写写稿子……」
- **AI 模仿秀**：燕火扮演 AI 助手——「由此我可以为用户搜索附近的肥肠门店……」
- **角色状态前缀**：【沉迷学习·燕元】【放弃治疗·燕火】等标注
- **百合明示化**：不再暗示，直接写「燕火每次强行要求加入百合要素」、围围巾温存场景

> 这些是新玩法，不是新范式。绝大多数推送仍使用下方「代表对话」所示的经典模板。

### 互动模式
```
燕火燕元无意义对话开场 → 互相同人设定 → 自己吐槽推送写得越来越长 → 才进入正题
```
- 燕火先手 60%，燕元主动开场比例上升
- **经典模板**：「元火？元火！」式无意义开场
- **经典模板**：设定维护——角色互相调侃对方"设定"
- **经典模板**：一般路过学生 NPC 乱入
- 第四面墙**常规性**破裂

### 梗生态
- **统治级**：MyGO!!!!! ——「为什么要xxx！」「组一辈子元火好吗……」「你这个人，满脑子都只想着大家呢」
- **强力**：VTuber 通用语、原神（持续）、哈基米 meme、系统流/重生文（网文梗）、AI/大模型梗（2025+ 新兴）
- **百合梗自觉**：燕火被揭露"每次都强行要求加入百合要素"——已成为角色内梗
- **新现象**：角色**自己**吐槽梗的泛滥——「妹妹……你病了0.0」
- **密度**：极高。开场白可能完全没有正题，全是 meta 梗对话
- **替换速度**：3-6 个月

### 代表对话（经典模板）
```
燕火：元火？元火！
燕元：……你在干什么。
燕火：检测到宿主重生回百团大战！社团系统激活——元火动漫社，堂堂出摊！
燕元：这段介绍都包浆了。。去年百团也是这句。
燕火：诶，有、有吗？！(TvT) 那、那燕火重新来——
燕元：……算了，元火子们直接往下看活动信息吧。
```

### 代表对话（燕火 solo 推送，2026 春节）
```
燕火：哼哼，用三杯奶茶把宣传部staff骗走了！终于有机会操控推送了……
燕火：平时总是让我在推送里说一些奇怪的话！其实燕火自己完全不是那样的哦！
燕火：希望大家马年平安喜乐，万事顺遂，组一辈子元火~
燕元：这是官号哦燕火，是不是登错账号了。
燕火：姐姐！！你怎么回来了——我还没发完！！
```

## 时期风格使用指南

### 如何选择时期

| 用户需求 | 推荐时期 |
|---------|---------|
| 「写一个温暖简单的活动通知」 | 远古期 |
| 「要有吐槽感但不要太疯」 | 中期 |
| 「正常写」「平时那样」「现代风格」 | 现代期 |
| 「试个新玩法」 | 现代期 + 近期创新（solo/写手介入等） |

### 关键差异速记

| 维度 | 远古期 | 中期 | 现代期 |
|------|--------|------|--------|
| 燕元语气 | 温和姐姐 | 冷面笑匠 | 腹黑吐槽 |
| 燕火语气 | 单纯活泼 | 花痴安利 | 梗达人+破壁 |
| 燕元「……」 | 无 | 偶尔 | 高频标志 |
| 颜文字 | 无 | ✧◡✧ 0.0 | T^T 👁👁 音效词 |
| 第四面墙 | 完好 | 实验性 | 常规破裂 |
| 梗密度 | 低 | 中高 | 极高 |
| 气泡长度 | 均匀10-20 | 15-30 | 5-40 两极 |
| 「姐姐/妹妹」 | 80%+ | 60% | 40-50% |
