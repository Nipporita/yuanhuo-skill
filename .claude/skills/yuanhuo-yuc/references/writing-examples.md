## 范例一：经典开场白（来自迎新晚会 repo）

```
燕火

姐姐，刚刚结束的晚会实在是太让人激动了！

燕元

你说的是哪一场晚会。

![](燕元眨眼表情)

燕火

诶。原来春晚已经过去了吗，我睡过去了吗，迎新晚会推送怎么才发。

燕元

你问做推送的去。他可能忙着上春晚呢。

![](燕元主表情)

燕火

算了不管了，这次让我们成功回到过去，看看春季迎新晚会元火子们带来了什么好吃的节目吧！
```

**为什么好：**
- 燕火用情绪化开场（兴奋），符合人设
- 燕元用反问冷吐槽「你说的是哪一场晚会」—— 一针见血
- 燕火的自爆「我睡过去了吗」制造笑点
- 燕元的「你问做推送的去」是 meta 吐槽（推送发晚了），社内梗拉满
- 燕火的「回到过去」时间线梗，自然过渡到 repo 正文
- 节奏：**热→冷→自爆→吐槽→重启**，4轮对话完成开场

## 范例二：经典的姐妹互动模式（来自迎新例会冒险）

```
燕火

哼哼！这叫微服私访，让我们看看最真实的元火子是什么样子！

燕元

但是我为什么有一种视奸元火子的感觉……

![](燕元主表情)

燕火

👁👁👁👁👁👁
```

**为什么好：**
- 燕火用「哼哼」开场——经典的装傻役自信满满
- 燕元用一个反问句完成冷静吐槽
- 燕火没有辩解，直接用颜文字「👁👁👁👁👁👁」自爆—— 视觉化幽默
- 3行对话 + 1个颜文字就完成了完整笑点

## 范例三：揭穿模式（来自迎新例会冒险）

```
燕火

燕火对抽奖什么的一点也不感兴趣哦！奖品什么的燕火才不要呢！

燕元

妹妹辣条吃饱啦？先擦擦嘴角的油再说话吧。

![](燕元主表情)
```

**为什么好：**
- 燕火的「一点也不感兴趣」= 经典口是心非（傲娇）
- 燕元不直接反驳，而是指出一个具体事实（嘴角有油）—— 一针见血的冷面吐槽
- 读者秒懂：燕火刚才偷吃了奖品区的辣条
- 2轮对话讲了一个完整小故事

## 范例四：合作安利模式（来自 cosplay 咖啡厅预热）

```
燕火

春天太舒服啦！风软软的，阳光暖暖的，最适合来一杯热咖啡，和同好贴贴！

燕元

没错没错！万众期待的元火 cosplay 咖啡厅就要和大家见面啦！

![](燕元主表情)

燕火

是那个能被喜欢的角色服务、聊番、听歌、拍照、超治愈的二次元咖啡厅吗！！

燕元

答对啦！不仅有超用心的 coser 小伙伴，还有超多惊喜活动和福利等着大家～
```

**为什么好：**
- 燕火用感性描述开场（春天、咖啡、贴贴）—— 氛围营造
- 燕元顺势「没错没错！」—— 合作模式，不做吐槽役
- 燕火用超长疑问句确认信息 —— 给燕元递话头
- 燕元「答对啦！」—— 补充更多细节
- 两人配合无间，像相声一样把活动信息自然传递

## 范例五：温情收尾（来自迎新晚会 repo）

```
燕元

感谢各位元火子们的付出！大家一起创造出的舞台真是无比耀眼呢！

燕火

没错没错！迎新晚会这么闪耀的舞台结束了让人都有些舍不得了呢！

燕元

这还只是元火春季蔷薇色大学生活的开始，远方的动漫文化节还在等着我们呢！

燕火

未来继续一起kirakira吧！这周末的动漫文化节和东方例会各位元火子记得来玩哦！
```

**为什么好：**
- 燕元先做正式感谢（姐姐的职责）
- 燕火用感情回应（妹妹的职责）
- 燕元引出后续活动（承上启下）
- 燕火用「kirakira」收尾 —— ACG语言 + 号召行动
- 温暖而不煽情，正式而不僵硬

## 通用技巧总结

1. **开场白** = 燕火情绪点燃 + 燕元冷吐槽 → 建立角色感
2. **中间评论** = 1-2轮对话，点到即止，不抢正文
3. **制造笑点** = 燕火自爆/夸张 + 燕元揭穿/冷吐槽
4. **传递信息** = 燕元负责事实，燕火负责感情
5. **收尾** = 燕元总结感谢 + 燕火感性号召
6. **meta 梗** = 吐槽推送发晚了/文案写烂了，拉近读者距离
7. **时间线梗** = 燕火的「EL PSY CONGROO」是万能穿越理由
